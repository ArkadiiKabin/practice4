## Описание решений

### 1A — Theatre Square

**Ссылка:** [Codeforces 1A](https://codeforces.com/problemset/problem/1/A)

**Задача:** необходимо покрыть прямоугольную площадь квадратными плитками заданного размера. Плитки нельзя разрезать, поэтому допускается выход за границы площади.

**Идея решения:**

Количество плиток по горизонтали и вертикали вычисляется отдельно с помощью округления вверх.

Для этого используется целочисленная формула:

- Количество плиток по горизонтали: `(n + a - 1) / a`.
- Количество плиток по вертикали: `(m + a - 1) / a`.

Итоговое количество плиток получается умножением двух значений.

**Алгоритм:**

1. Считать размеры площади и размер плитки.
2. Вычислить количество плиток для каждой стороны.
3. Перемножить полученные значения.
4. Вывести результат.

**Сложность:**

- Время: `O(1)`.
- Дополнительная память: `O(1)`.

### 479A — Expression

**Ссылка:** [Codeforces 479A](https://codeforces.com/problemset/problem/479/A)

**Задача:** необходимо найти максимальное значение выражения из трёх заданных чисел, используя сложение, умножение и скобки, сохраняя исходный порядок чисел.

**Идея решения:**

Так как чисел всего три, можно рассмотреть все допустимые варианты расстановки операций и скобок.

Основные варианты:

- `a + b + c`
- `a * b * c`
- `a + b * c`
- `a * (b + c)`
- `(a + b) * c`
- `a * b + c`
- `(a + b + c)`

После вычисления вариантов выбирается максимальное значение.

**Алгоритм:**

1. Считать три числа.
2. Вычислить значения возможных выражений.
3. Сравнить результаты.
4. Вывести максимальное значение.

**Сложность:**

- Время: `O(1)`.
- Дополнительная память: `O(1)`.

### 1915F — Greetings

**Ссылка:** [Codeforces 1915F](https://codeforces.com/problemset/problem/1915/F)

**Задача:** необходимо определить количество пар людей, которые встретятся на маршрутах между своими домами и работой.

**Идея решения:**

Задача сводится к подсчёту инверсий в последовательности координат.

Сначала маршруты сортируются по координате начала. Затем рассматриваются конечные координаты.

Если у двух маршрутов начало первого не больше начала второго, но конец первого находится правее конца второго, то маршруты пересекаются в требуемом смысле.

Для эффективного подсчёта таких пар применяется сортировка слиянием или дерево Фенвика.

**Алгоритм:**

1. Считать количество маршрутов и их координаты.
2. Отсортировать маршруты по координате начала.
3. Получить последовательность координат окончания.
4. Подсчитать количество инверсий.
5. Вывести количество подходящих пар.

**Сложность при использовании сортировки слиянием:**

- Время: `O(n log n)`.
- Дополнительная память: `O(n)`.

### 1167B — Lost Numbers

**Ссылка:** [Codeforces 1167B](https://codeforces.com/problemset/problem/1167/B)

**Задача:** требуется восстановить скрытую перестановку из шести известных чисел.

Задача является интерактивной: программа отправляет запросы, получает ответы от интерактора и использует их для восстановления последовательности.

**Идея решения:**

Для восстановления перестановки используются произведения элементов с определёнными индексами.

В частности, запрашиваются произведения:

- `a[1] * a[2]`
- `a[2] * a[3]`
- `a[4] * a[5]`
- `a[5] * a[6]`

Полученные значения позволяют восстановить все шесть элементов с использованием известного набора чисел.

**Алгоритм:**

1. Отправить четыре запроса интерактору.
2. Считать четыре ответа.
3. Перебрать возможные перестановки известных чисел.
4. Найти перестановку, произведения соседних элементов которой совпадают с полученными ответами.
5. Вывести найденную последовательность.

**Особенности реализации:**

- После каждого запроса необходимо выполнить `flush`.
- При получении ответа `0` программа должна немедленно завершиться.
- Ответ выводится в формате `! a1 a2 a3 a4 a5 a6`.
- Количество запросов не должно превышать четырёх.

**Сложность:**

- Время: `O(1)`, поскольку количество элементов и запросов фиксировано.
- Дополнительная память: `O(1)`.

## Тестирование

Каждое решение проверяется на платформе Codeforces.

При тестировании учитываются:

- Примеры из условия.
- Минимальные входные данные.
- Граничные значения.
- Случаи с одинаковыми координатами.
- Различные варианты расположения маршрутов.
- Корректность обработки интерактивных ответов.

Для интерактивной задачи дополнительно проверяется правильность формата запросов, количество обращений к интерактору и обязательный сброс буфера вывода.
